# LogiPulse | Enterprise Fleet Telemetry & Smart Dispatch Platform

A full-stack logistics management and real-time fleet telemetry web platform built with React, Node.js, Express, Socket.io, Leaflet, and MongoDB.

## Features
- **Real-Time GPS Telemetry**: Live interactive road tracking using Leaflet, Google Maps, OpenStreetMap, and CartoDB.
- **Smart TSP Route Optimization**: Multi-stop routing algorithm with dynamic duration and distance estimations.
- **Role-Based Workflows**: Tailored console views for Admin, Dispatcher, Driver, Finance, and Consignee Customer personas.
- **Bilingual Internationalization**: Seamless instant switching between English and Hindi.
- **Interactive Light & Dark Themes**: Warm fleet yellow inside dashboard, sleek nocturnal dark mode, and high-contrast blue & white login portal.
- **24/7 AI Customer Support Chatbot**: Instant shipment tracking, status checking, and customer assistance.

## Getting Started

### 1. Backend Server
```bash
cd server
npm install
npm run dev
```
Runs on `http://localhost:5050`.

### 2. Frontend Client
```bash
cd client
npm install
npm run dev
```
Runs on `http://localhost:3000`.
